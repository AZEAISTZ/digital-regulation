# การกำกับดูแลการแข่งขันในยุคดิจิทัล — เว็บทบทวนบทเรียน

เว็บไซต์ทบทวนบทเรียนจากสไลด์บรรยายพิเศษ "การกำกับดูแลการแข่งขันในยุคดิจิทัล" (วิชา EC483/ศ.483)
บรรยายโดยคุณมนยศ วรรธนะภูติ รองเลขาธิการคณะกรรมการการแข่งขันทางการค้า
วันที่ 28 ตุลาคม 2569 คณะเศรษฐศาสตร์ มหาวิทยาลัยธรรมศาสตร์

เนื้อหาถอดความจากสไลด์เท่านั้น ทุกย่อหน้าติดป้ายอ้างอิงหน้าสไลด์ `(สไลด์ น. X)`
ข้อมูลเสริมเพิ่มเติมจากภายนอกอยู่ในกล่อง "ข้อมูลเสริมภายนอก" แยกจากเนื้อหาสไลด์อย่างชัดเจน
**ไม่มีการเผยแพร่ไฟล์หรือภาพหน้าสไลด์ต้นฉบับ** ตามเงื่อนไขลิขสิทธิ์ที่ระบุในเอกสาร

## ดูตัวอย่างในเครื่อง

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000/` ในเบราว์เซอร์

## โครงสร้างโปรเจกต์

- `index.html`, `module.html`, `quiz.html`, `glossary.html` — หน้าเว็บหลัก (static, ไม่มีขั้นตอน build)
- `content/` — เนื้อหา (modules.json, modules/*.md, quiz.json, glossary.json)
- `assets/` — CSS และ JavaScript
- `BRIEF.md`, `CLAUDE.md`, `PROGRESS.md`, `OUTLINE.md`, `VERIFICATION.md`, `QUESTIONS.md` — เอกสารกระบวนการจัดทำเว็บ (ไม่ใช่ส่วนของเว็บไซต์)
- `materials/`, `work/` — ไฟล์สไลด์ต้นฉบับและไฟล์ชั่วคราว (อยู่ใน .gitignore ไม่ถูกเผยแพร่)
